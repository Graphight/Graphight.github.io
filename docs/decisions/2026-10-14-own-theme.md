# Own theme

- Status: Accepted
- Created: 2026-10-14
- Reflects: branch `own-theme`, commits `ece8a4a` to `91f17c7`, built locally with the `github-pages` gem and checked by eye on a phone width and a laptop in both modes; a design canvas drawn on 2026-10-14 in a Claude session, five directions (Notebook, Editor, Index, Isobar, Field), each a home page and an article page with a dark and light toggle, judged by eye (link under References); the Warm Burnout palette at warmburnout.com

## Summary
The site leaves the Slate remote theme for its own layouts and one stylesheet built on the Warm Burnout palette, with a dark and a light mode.
The question was: can the site drop Slate for its own layouts and one stylesheet of Warm Burnout tokens, in both modes, with nothing GitHub Pages cannot build?
Yes: the site builds with the `github-pages` gem alone, and no theme is configured.

## Context
`_config.yml` set `remote_theme: pages-themes/slate@v0.2.0`.
The three layouts in `_layouts/` were copies of Slate's, so the markup was owned and the look was not.
They leaned on Slate in two places: `assets/css/style.css` was Slate's compiled stylesheet, and `_includes/head-custom.html` included `head-custom-google-analytics.html`, which only Slate provides.
Warm Burnout is an editor palette: it names syntax roles and two backgrounds, and has no surface, border or heading colour.

## Design
- **One shell layout.** `_layouts/default.html` is the only full HTML document; `page.html` and `article.html` wrap it, and the article adds "↑ Back to top".
  The header is the name on the left and the nav on the right; the current page's nav link is marked with `aria-current`, and articles mark Writing.
  The footer carries GitHub, LinkedIn and itch.io as text links, the year and the palette credit.
- **Tokens are CSS custom properties on `:root`** in `assets/css/site.scss`, written once per mode as a Sass mixin and applied to light by default, to dark under `prefers-color-scheme: dark`, and to whichever mode `data-theme` names.
  The mixin is the reason the file is Sass: it states each mode once instead of twice.
- **Three tokens are derived, not taken from the palette**: `surf` (`#221c15` / `#ebe1d0`), `line` (`#3a3027` / `#d6c8b2`) and `hi` (`#ece6da` / `#1f1b16`).
- **The mode follows `prefers-color-scheme`**, and a toggle in the nav overrides it, kept in `localStorage` under `theme`.
  A one-line inline script in `<head>` sets `data-theme` before first paint.
  The button names the mode a click gives ("Switch to dark"), and relabels when the OS mode changes.
  The button is hidden until its script runs, so a visitor without JavaScript gets the OS mode and no dead button.
  A blocked `localStorage` falls back to the OS mode.
- **Type is Bricolage Grotesque for headings, Atkinson Hyperlegible for prose and JetBrains Mono for code and the footer**, from Google Fonts.
- **Burnt orange (`kw`) is the link colour**; the footer links are steel blue (`ty`).
- **`interactive.css` maps the widget border and track to `line` and its accent to `kw`**, so a widget follows the mode.
- **Google Analytics is dropped**: the include resolved to Slate's, which rendered nothing because `google_analytics` was never set.
- **`theme: null` is set in `_config.yml`.** Without it the `github-pages` gem falls back to the Primer theme, which builds an unused `style.css` and supplies its layouts as a fallback.
- **`jekyll-seo-tag` is listed in `plugins`**, so `{% seo %}` does not depend on a theme loading it.
- **The icon row on the home page is gone.** Its PNGs are black on transparent, which does not read on the dark background, and the footer already carries the same three links.

## Alternatives considered
Each was drawn on the canvas and set aside.
- **Notebook**: one serif column, closest to the site today. The safest and the most boring; it stays the fallback if Field cannot be made to work.
- **Editor**: the site as a Warm Burnout IDE, with a file tree, tabs and line numbers. Charming, and painful to read a whole article in.
- **Index**: an identity sidebar beside dense content. Built for a recruiter's skim, and its wide format wraps poorly on a phone.
- **Isobar**: a bold hero over generated contour lines. It became Field; the contours over-indexed on weather.
- **Keeping Slate and overriding its colours.** Slate's header, gradients and fonts are most of its look, so little would be left of it.
- **A plain `.css` file with the dark block written twice.** Shorter to build, and the two copies drift.

## Consequences & open questions
- The site now reads as plain Markdown in Field's colours and type; the title band, hero, home page and code colours are the other proposals.
- `theme: null` has been checked against a local `github-pages` build, not yet against a deploy.
- The widget track is `line` on `bg`, about 1.4:1 in both modes, below the 3:1 for parts of a control; no page uses the widget yet.
- The Projects embed is fixed at 540px and scrolls sideways on a phone (proposal `projects-embed`).
- `resources/icons/GitHub.png`, `LinkedIn.png` and `Itch.png` are deleted with the icon row.
- Self-hosting the three fonts drops the Google Fonts request and costs about 200 KB in the repository; whether that is worth it is open.
- The site credits the palette in its footer; Warm Burnout is MIT licensed, so the credit is courtesy, not a condition.
- The favicon is still unset.

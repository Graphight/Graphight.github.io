# Open proposals

In build order.
Each is sized to one session and answers one question; "no" is a valid answer.
All five come from one design canvas drawn on 2026-10-14 (References in decision `own-theme`), which settled on its fifth direction, Field.

1. [Code highlighting](code-highlighting.md): can Rouge's token classes map onto Warm Burnout's roles closely enough that a code block reads like the editor theme?
2. [Work history](work-history.md): can the work history live in one data file, so the home page, About and the resume PDF stop disagreeing? Adds Sprout.
3. [Home page](home-page.md): can the home page give a recruiter the numbers and the timeline in one scroll, without turning the site into a CV? Stands on the work history.
4. [Hero animation](hero-animation.md): does a looping clustering animation behind the name say "ML and physics" without slowing the page or pulling the eye off the text? Stands on the home page.
5. [Projects embed](projects-embed.md): can the Space Probe embed fit a phone and keep its click to load?
